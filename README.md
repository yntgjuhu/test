# 生物棲息地點網站

這是一個靜態網站，介紹地球上各種生物的棲息地點。

## 內容

網站涵蓋以下棲息地點：
- 森林
- 海洋
- 沙漠
- 草原
- 凍原
- 城市

每個部分都包含簡短描述和示例生物。

## 功能

- **搜尋生物**：輸入生物名字（如“熊”），網站將顯示該生物的圖片和棲息地。
- 支援的生物範圍廣泛，包含森林、海洋、沙漠、草原、凍原和城市中的多種物種，並持續擴充更多海洋生物，例如小丑魚、水母、海葵、白鯨、海鰻、鱟、河豚和大王烏賊。

## 如何運行

1. 打開 `index.html` 在瀏覽器中查看網站。
2. 或者，使用 Python 啟動本地伺服器：
   ```
   python -m http.server 8000
   ```
   然後在瀏覽器中訪問 `http://localhost:8000`。

## 文件結構

- `index.html`: 主頁面
- `style.css`: 樣式表
- `script.js`: JavaScript 腳本，用於互動效果和搜尋功能

## 技術

- HTML5
- CSS3
- JavaScript (ES6)
